PR Board

Every open PR you wrote and every PR waiting on your review, in one list. You tag each one with your own status, like Testing pending by me, and it stays with you across devices.

It needs a GitHub token. Create one here:

  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Resource owner: the org your PRs live in. Repository access: All repositories.
  3. Set these permissions, then generate and copy the token:
Pull requests
Read-only. Lists your PRs and review requests.
Metadata
Read-only. Added automatically.
Gists
Read and write (under Account permissions). Saves your statuses to a private gist.

The token is stored only in this browser and is sent only to api.github.com. PRs across several orgs? Use a classic token with the repo and gist scopes instead, since a fine-grained token covers one org.
